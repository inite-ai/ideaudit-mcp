# Contributing to ideaudit-mcp

This repository is a **generated mirror**: it is rebuilt and force-pushed from
the private monorepo that develops it, so a pull request here would be
overwritten by the next sync. Changes land in the monorepo, made by
maintainers. Issues are the right channel, and they are read.

- **A number you disagree with, or can't reproduce?** Open a
  [Bug report](https://github.com/inite-ai/ideaudit-mcp/issues/new?template=bug_report.yml)
  with the tool, the exact input and the output. Every tool is deterministic,
  so that settles it. Use made-up numbers.
- **An idea?** Open a
  [Product idea](https://github.com/inite-ai/ideaudit-mcp/issues/new?template=product-idea.yml).
  Plain words are fine.
- **Using an AI agent?** [AGENTS.md](AGENTS.md) is the source of truth for
  people and agents alike — why `dist/` is committed, the rules, how to run
  and check the local server, and the idea → issue loop. With Claude Code,
  open the repo and run `/contribute`; with any other agent, say "read
  AGENTS.md and help me report …".

Security problems: please don't open a public issue — see [SECURITY.md](SECURITY.md).
